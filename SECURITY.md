# Security policy

## Supported versions

Only the [latest release](../../releases/latest) receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead: [Security → Report a vulnerability](../../security/advisories/new). You should get a response within a few days.

## What Focus Reader does with your screen

When **Blur surroundings** is enabled, the app captures the screen a few times per second to draw the blurred background. The capture stays in memory only: it is never saved to disk or sent anywhere, and the app makes no network connections.
